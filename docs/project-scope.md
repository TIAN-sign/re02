# 项目范围

## 已确定

- 游戏类型：街机式横版一对一格斗。
- 项目独立，所有实现放在本仓库同一个项目根内。
- 使用云端 Git 开发，交付可识别的提交，通过 PR 和本地拉取审核。
- 角色、场景、音效和视觉表现采用原创或授权清晰的资产，不复制《街头霸王》素材。

## 首个可玩版本（已确认）

- Godot 4.6.3，Windows；本地双人和训练模式，支持键盘与手柄。
- 一个原创角色镜像对战、一个擂台，先用简单形体占位。
- 移动、跳跃、蹲下、攻击、防御、投技、短连段、KO 与重赛。
- 固定 60 帧战斗逻辑，显示输入历史与判定框。
- 联网和正式画风不在本轮。具体接口和职责见 [共享接口契约](interface-contract.md)。

## 后续决定

| 决策 | 需要确定的内容 |
| --- | --- |
| 美术方向 | 正式画面风格、资产来源与制作规模 |
| 扩展平台 | Windows 之外的平台需求 |
| 后续对战范围 | CPU 或联网需求及其独立排期 |

首版已按上述范围开始工程。后续扩展决策应说明选择、原因、影响及对应 PR。

## 建议的交付顺序

1. **初始化基线**：范围、协作规则、本地审核流程与仓库检查，已建立。
2. **技术基线**：Godot 4.6.3、唯一运行入口、依赖版本与启动说明，已建立。
3. **可玩切片**：已实现双方角色完整一局与训练流程，完成 Linux 自动验证及实际渲染；Windows 实机和实体手柄等待本地验收。
4. **后续扩展**：按实际审核结果安排角色、招式、美术和其他功能。

每次交付以可核验行为与提交为依据，不以文档数量、检查项数量或代理数量推算完成率。
