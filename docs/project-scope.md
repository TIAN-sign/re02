# 项目范围

## 已确定

- 游戏类型：街机式横版一对一格斗。
- 项目独立，所有实现放在本仓库同一个项目根内。
- 使用云端 Git 开发，交付可识别的提交，通过 PR 和本地拉取审核。
- 角色、场景、音效和视觉表现采用原创或授权清晰的资产，不复制《街头霸王》素材。

## 尚未确定

| 决策 | 需要确定的内容 |
| --- | --- |
| 引擎与语言 | 根据目标平台、格斗逻辑可测试性及本地运行条件选择，初始化不引入运行时依赖 |
| 目标平台与输入 | 首先支持的操作系统或浏览器，以及键盘、手柄需求 |
| 美术方向 | 2D 或其他表现方式、画面风格、资产来源与制作规模 |
| 首版对战范围 | 本地双人、对 CPU 或联网的取舍；不默认加入或排除联网 |
| 首个可玩切片 | 双方角色、基础移动与攻击、防御、命中反馈、生命值与胜负流程的最小组合 |

在上述选择形成记录后再开始引擎工程。每项决策应说明选择、原因、影响及对应 PR。

## 建议的交付顺序

1. **初始化基线**：范围、协作规则、本地审核流程与仓库检查。当前版本属于此阶段，没有可运行游戏。
2. **技术基线**：确定引擎和首版范围，提交唯一可运行入口、依赖版本与启动说明。
3. **可玩切片**：完成双方角色的完整一局流程，提供可复现的操作验收步骤。
4. **后续扩展**：按实际审核结果安排角色、招式、美术和其他功能。

每次交付以可核验行为与提交为依据，不以文档数量、检查项数量或代理数量推算完成率。
